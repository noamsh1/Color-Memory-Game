Color Memory Game
-
A Memory game where you need to match identical tiles made of different colors. The game is made both for Android and Windows.

You can choose the grid size and the game mode: In singleplayer mode you try to complete the board in the fewest turns possible. In 2-player mode, you compete with a friend and whoever matches more tiles wins.

To play the game, download the correct version for your device from Releases.
